# DAKA — 把生活变成你的经验值

离线 Android MVP，黑白视觉，包名 `com.daka.life`。Android 8.0（API 26）及以上。

## 重要交付说明
这是源码工程，不是已编译 APK。本环境没有 Android SDK、Gradle 下载及真机测试能力；**尚未验证 Android 构建或真机行为**。首次 CI 可能暴露依赖、SDK 或设备兼容问题，应以 Actions 日志和实机测试为准。不要将此版本直接作为付费商业产品发布。

## 上传 GitHub 并获取安装包
1. 解压源码 ZIP。在 GitHub 创建仓库（不必先添加 README）。
2. 将 ZIP 内工程根目录的内容放在仓库根目录：`settings.gradle`、`app/`、`.github/` 必须同级。不要仅上传 ZIP，也不要多套一层文件夹。
3. 建议使用 Git 推送整个解压目录，确保包含隐藏目录 `.github`。网页上传也可以，但务必检查 `.github/workflows/android.yml` 是否确实存在。
4. 推送 main/master 后，打开 Actions → Build DAKA APK。若自动未触发，可在该工作流点击 Run workflow；仓库需要启用 Actions。
5. 成功后，在该次运行的 Artifacts 下载 DAKA-debug-APK；解压其中的 APK，传到安卓手机后安装。手机可能要求允许当前文件管理器安装未知来源应用。
6. 这是开发测试用 debug APK，不是 Play 商店正式签名版本。不同 CI 运行的临时 debug 签名可能不同，不能保证覆盖安装。重新安装前先备份数据。

## 本地编译
需要 JDK 17、Android SDK platform 35 / build-tools 35.0.0、Gradle 8.9、联网下载依赖。配置 ANDROID_HOME 或 local.properties 的 sdk.dir。
运行 `gradle :app:assembleDebug`。本项目故意不包含 gradle-wrapper.jar；CI 使用 setup-gradle 安装固定 Gradle。
建议首次构建成功后运行 `gradle wrapper --gradle-version 8.9`，将生成的 wrapper 文件加入仓库，再使用 `./gradlew :app:assembleDebug`。

## 已实现
- 打卡记录数量、行动日期、真实录入时间、笔记及压缩图片，历史补卡，不允许未来日期。
- 创建习惯、三个技能主干及自定义技能；每单位 XP 可配置；按记录实时重算 XP、等级及节点解锁。
- 最近 84 天热力图，日/周/月/年滚动区间柱状图与上一等长区间比较。统计记录条数，不将分钟、公里等不同单位直接加总。年图为 12 个时间桶，不是自然月。
- 人生时间轴由上到下 100→0 岁，生日定位、事件新增及删除。100 岁只是展示范围。
- 目标按年龄/年份规划、四种属性、四种状态，分组及排序时间轴。
- 累计型目标关联打卡；完成自动更新；放弃归档且不扣 XP。
- 勾选习惯/技能/目标成就；习惯 50/200/1000 阶梯；技能 Lv.5；目标自选图标；未完成锁定显示及详情。
- 达成日期与实际首次记录解锁日期分别保存；撤销打卡重新计算 XP 和成就。进度跌破条件会撤销点亮，下次达标重新记录。
- 纪念卡导出 PNG（文字与勋章），关联打卡照片/心得在成就详情展示。
- 模板去重导入，黑白主题切换，JSON 备份/覆盖恢复，恢复基础校验。
- Android 系统文件选择器选照片/备份，系统文件保存界面保存 JSON/PNG，无广泛存储权限。
- 不申请网络权限，不对外加载页面，使用 AndroidX WebViewAssetLoader 加载打包网页资源。

## 未实现 / 已知限制
- 原生控件 UI（当前是 Android 原生外壳 + 本地 WebView 界面），云同步、账号、提醒通知、商业化支付、社交账号分享、Play 正式发布签名。
- 可拖拽技能连线、自定义节点解锁规则、人生滚动震动、自然周/月/年统计、折线图、动态粒子勋章、照片嵌入导出卡片。
- 已创建习惯/技能的编辑和删除（日志可撤销；目标/人生事件可删除）。
- 目标完成本身不会额外奖励 XP；XP 当前只来自打卡，避免重复计分。非关联目标手动完成。
- XP 和个人记录均由本地自报；未来日期校验不是可靠防作弊，也不能防止用户改手机时间或修改备份。
- 数据用 WebView localStorage 保存，容量受设备实现影响。图片多时可能不足；保存失败会回滚该次变更。请定期导出备份，不建议存大量照片。
- 目标关联现有习惯全部历史总量，不设置起始日期。目标退回其他状态时，累计进度仍达标会重新自动完成。
- 首条打卡至达成的天数是日历跨度，不是连续天数。年龄目标的时间轴排序按出生年份近似换算。
- PNG 导出保存后由用户在相册/文件管理器分享；不直接调用安卓分享面板。图标字形随设备系统字体变化。
- Android 返回键关闭弹窗；无弹窗时留在应用，使用系统 Home/最近任务退出。
- 无默认模拟记录；所有初始统计为零。
